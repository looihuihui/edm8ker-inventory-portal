Quick reference for storing, taking and tracking materials in the Edm8ker room.

Rules

Read once, follow always. These keep the room fast, safe and organised for everyone.

Inventory Rules
CHECK OUT (Taking items)
  • TAKE the item from the correct zone and bin.
  • RECORD it on the log sheet.
  • Person-in-charge will UPDATE the Inventory Master Sheet by end of day.
CHECK IN (Returning / restocking)
  • RETURN / RESTOCK into the correct bin.
  • RECORD it on the log sheet.
  • Person-in-charge will UPDATE the Inventory Master Sheet by end of day.
Floor & Room Ground Rules
Keep the room usable for everyone
  • FLOOR MUST BE CLEAR – no bags or loose items on the ground.
  • DO NOT place items “temporarily” on the floor. Store them properly immediately or at the "TO BE ORGANISED" rack.
  • RETURN items to the correct bin. DO NOT MIX different items in one bin.
  • If a bin is FULL, CREATE a new bin, LABEL it and record it on the log sheet.
  • Fold TABLE and STOOL after use and return to assigned area.
  • Valuable devices stay in the LOCKED cabinet.

New to the room? Start here.

These short guides show you exactly how to store and take items properly.

Overview How the system works (in one glance)
Goal: find & return items quickly, without touching a computer.
1. The room is split into ZONES (A–G) such as Tools, General Craft, Decorative, Electronics, Kits and Valuables.
2. Each item type lives in ONE bin with a bin ID (for example: B2A).
3. You NEVER need to search in Excel while packing. Just use zones, bin labels and the log sheet.
4. The person-in-charge uses the log sheet to update the Inventory Master Sheet later.
Check Out Taking items (for packing or programmes)
1. Find the correct ZONE using the wall labels.
2. Look for the correct bin ID (e.g., C3A).
3. Take only the quantity you need.
4. Record on log sheet: Zone, Bin No., Qty OUT, Purpose, Name.
5. PIC will update the Master Sheet later.
Check In Returning / restocking items
Always log returns so stock stays accurate.
1. Confirm the correct bin ID for the item.
2. Restock the correct quantity into the correct bin.
3. If the bin is full, create a new bin and label it clearly. Remember to note “NEW BIN” on the log sheet so the PIC can update the master inventory easily.
4. Record: Zone, Bin No., Qty IN, Purpose, Name.
5. PIC will update the Master Sheet later.
Bin Naming System (Examples)

How bins are labelled so everyone can find items fast and avoid confusion.

How to read the Bin Number Example: E1A, E2A, E2B
Bin Number examples
  • E1A = Electronics Category, Item 1, First Bin
  • E2A = Electronics Category, Item 2, First Bin
  • E2B = Electronics Category, Item 2, Second Bin

E2A & E2B keep the same item but with different quantities. Never mix them. Each bin has its own quantity.

If you create a new bin for an item, always label it properly and write it in the log sheet so the PIC can update Excel.

New Taobao Item? Follow This.

Goal: Prevent confusion when Taobao names are different for the same item.

Steps (Check In) What to do with new Taobao stock
  • Ignore the Taobao name - names vary, not important.
  • Identify the actual item (e.g., motor, pompoms, wires).
  • Check the Category List (A–G) to see which group it belongs to.
  • Look for the correct category zone.
  • Put into the correct bin:
    • If the bin exists → just add inside.
    • If full → create a second bin (e.g., D3A → D3B). Write simple item name on the whiteboard label (e.g., “pompom”). Do NOT use the Taobao name.
  • Record the restock on the paper log sheet.
  • Excel is NOT updated by everyone - only the person-in-charge (PIC) updates it later.

Tip: Update the Material List with a Category Zone column. Makes packing & restocking faster.

Excel Maintenance (1–2 People Only)

Goal: Keep the system accurate without stressing everyone.

PIC Responsibilities For the person maintaining the Excel only
What the PIC needs to do
  • Update Excel daily or weekly (daily recommended).
  • Update bin quantities
  • Create new bin numbers when needed (e.g., B1C, C4B).
  • Keep category names consistent and standardised.
  • Ensure the digital list stays clean and minimal.
