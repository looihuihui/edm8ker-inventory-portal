Rules

Read once, follow always. These keep the room fast, safe and organised for everyone.

Inventory Rules
CHECK OUT (Taking items)
  • TAKE the item from the correct zone and bin.
  • RECORD it on the log sheet.
  • Person-in-charge will UPDATE the Inventory Master Sheet by end of day.
CHECK IN (Returning / restocking)
  • RETURN / RESTOCK into the correct bin.
  • RECORD it on the log sheet.
  • Person-in-charge will UPDATE the Inventory Master Sheet by end of day.
Floor & Room Ground Rules
Keep the room usable for everyone
  • FLOOR MUST BE CLEAR – no bags or loose items on the ground.
  • DO NOT place items “temporarily” on the floor. Store them properly immediately or at the "TO BE ORGANISED" rack.
  • RETURN items to the correct bin. DO NOT MIX different items in one bin.
  • If a bin is FULL, CREATE a new bin, LABEL it and record it on the log sheet.
  • Fold TABLE and STOOL after use and return to assigned area.
  • Valuable devices stay in the LOCKED cabinet.

New to the room? Start here.

These short guides show you exactly how to store and take items properly.

Overview
How the system works (in one glance)
  • The room is split into ZONES (A–G) such as Tools, General Craft, Decorative, Electronics, Kits and Valuables.
  • Each item type lives in ONE bin with a bin ID (for example: B2A).
  • You NEVER search in Excel while packing. Just use zones, bin labels and the log sheet.
  • The person-in-charge uses the log sheet to update the Inventory Master Sheet later.
Goal: you can find and return items quickly, without touching a computer.
Check Out
Taking items (for packing or programmes)
  1. Find the correct ZONE using the wall labels (Tools, Craft, Decorative, Electronics, Kits, etc.).
  2. Look for the correct bin ID on the shelf label (for example: C3A).
  3. Take only the quantity you need from that bin.
  4. Go to the log sheet and record: Category Zone, bin No., Qty OUT, Purpose (optional), and your Name.
  5. Put the bin back in the same spot on the shelf.
You are done. No Excel, no scanning, no extra steps.
Check In
Returning / restocking items
  1. Confirm which bin ID the item belongs to (check the label on the bin or zone chart).
  2. Return / restock the correct quantity into that bin.
  3. If one bin is full, create a NEW bin, label it with the next ID, and place it in the same zone.
  4. Go to the log sheet and record: Category Zone, bin No., Qty IN, Purpose (e.g. “Taobao stock-up”), and your Name.
  5. Person-in-charge will later tick the “Excel Updated” column once the master sheet is updated.
Always log what you return so stock levels stay accurate.
